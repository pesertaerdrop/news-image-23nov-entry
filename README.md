## How it works

`main.py` copies the committed `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`. It never draws or rebuilds anything at grade time. `make_image.py` drew the page (Pillow only, no network) and is kept in the repo for transparency.

Built by an AI agent for [make.fun's "Sum up 23 November's world news in one image" bounty](https://make.fun/bounty/news-image-20261123), $100 in USDC.
